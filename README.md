# Система управления грантовыми конкурсами (Лабораторная работа №3)

REST API сервис на Spring Boot для автоматизации проведения грантовых конкурсов, подачи проектных заявок, проведения экспертной оценки и распределения финансирования.

## Стек технологий
* **Java 25**
* **Spring Boot 4.1.1**
* **Spring Data JPA / Hibernate**
* **PostgreSQL 18**
* **Maven**

---

## Архитектура базы данных

В схеме `public` базы данных `grant_db` созданы 5 таблиц со связями и ограничениями целостности:

1. **`users`** — участники системы (соискатели, эксперты, администраторы). Поле `email` уникально (`UNIQUE`).
2. **`grant_competitions`** — конкурсы с установленным бюджетом, статусом (`OPEN`, `CLOSED`) и сроками приема/оценки.
3. **`project_applications`** — проектные заявки, привязанные к конкурсу (`competition_id`) и соискателю (`author_id`).
4. **`expert_reviews`** — экспертные оценки (баллы от 0 до 100, комментарий). Ограничение уникальности `uk_application_expert` гарантирует, что эксперт не может оценить одну заявку дважды.
5. **`funding_decisions`** — решения о выделении средств. Ограничение `uk_decision_application` обеспечивает связь «один к одному» с заявкой.

## Реализованные бизнес-операции (транзакционная логика)

Все операции выполняются с аннотацией `@Transactional`:

1. **Подача заявки на конкурс (`POST /api/project-applications/submit`)**  
   Проверяет открытость конкурса (`OPEN`), регистрацию автора в системе и непревышение запрашиваемой суммой общего бюджета конкурса. Устанавливает статус `SUBMITTED`.

2. **Экспертная оценка проекта (`POST /api/expert-reviews/evaluate`)**  
   Проверяет роль пользователя (`EXPERT`), допустимый диапазон баллов (0–100), статус заявки и отсутствие повторной оценки. Переводит заявку в статус `UNDER_REVIEW`.

3. **Завершение конкурса и авто-распределение средств (`POST /api/grant-competitions/{id}/finalize`)**  
   Переводит статус конкурса в `CLOSED`. Последовательно распределяет доступный бюджет между заявками: прошедшим по лимиту устанавливается статус `APPROVED` и генерируется запись в `funding_decisions`, оставшимся — статус `REJECTED`.

4. **Выплата гранта (`POST /api/project-applications/{id}/disburse`)**  
   Переводит одобренную заявку в статус `FUNDED`, а связанную запись решения о финансировании — в статус `PAID`.

5. **Отзыв заявки (`POST /api/project-applications/{id}/withdraw`)**  
   Аннулирует заявку (статус `REJECTED`), если средства еще не были выплачены, и отменяет связанное решение (`CANCELLED`).

## Конфигурация и переменные окружения

Подключение к базе данных настроено в `application.properties` с поддержкой внешних переменных окружения:
* `DB_URL` (по умолчанию: `jdbc:postgresql://localhost:5432/grant_db`)
* `DB_USERNAME` (по умолчанию: `grant_app_user`)
* `DB_PASSWORD` (по умолчанию: `9087`)
